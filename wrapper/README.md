# OpenCraft headset app (Unity wrapper)

> This is OpenCraft's modified copy of [QCXR-XR-Wrapper](https://github.com/QuestCraftPlusPlus/QCXR-XR-Wrapper). It stays under the license in [LICENSE](LICENSE). [MODIFICATIONS.md](MODIFICATIONS.md) lists every change. The original authors are credited at the bottom of this file.
[![GPLv3 License](https://img.shields.io/badge/License-GPLv3-green.svg)](https://choosealicense.com/licenses/gpl-3.0/)

A launcher for standalone VR headsets, made with Unity and Pojlib.
<br>Build it with Unity 2022.3 LTS (this project is set to 2022.3.62f3) and the Android Build Support module.
